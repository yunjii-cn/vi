# 云集智能视频创意站 — 商业计划书

> 版本：v1.0 | 日期：2026-06-03

---

## 一、执行摘要

云集智能视频创意站是一款基于 LTX Studio 的 AI 视频生成桌面软件，核心价值是**降低 AI 视频本地化使用门槛**和**解决国内网络适配问题**。

本计划以**轻资产、快变现、重服务**为核心原则，通过"微信登录+时间卡密"体系，结合云电脑代理和人工安装服务，在1个月内实现首笔收入，6个月内实现稳定现金流。

**三大收入支柱**：

| 支柱 | 启动时间 | 首笔收入预期 | 模式 |
|------|---------|-------------|------|
| 云电脑时长代理 | 第2个月 | 按用户量线性增长 | 时间卡密 |
| 1对1安装服务 | 第1个月 | 即时 | 按次付费 |
| 云端API代理 | 第3个月 | 按调用量增长 | 按量计费 |

## 二、产品与市场

### 2.1 产品定位

**一句话定位**：国内最好用的 AI 视频生成一站式工具——从安装到出片，全程无忧。

**核心差异化**：

- 本地推理零门槛（6GB显存即可运行）
- 国内网络全适配（镜像源自动测速、HF-Mirror、Gitee双源更新）
- 硬件自适应（GPU检测→自动推荐参数→FP8量化→显存保护）
- 一键部署维护（Python环境、模型下载、依赖修复全自动）

### 2.2 目标用户画像

| 用户类型 | 占比 | 核心需求 | 付费意愿 | 付费能力 |
|----------|------|---------|---------|---------|
| 个人创作者/自媒体 | 50% | 快速出片、低成本 | 中 | 低（月50-200元） |
| 小型工作室/电商 | 25% | 批量生产、稳定可靠 | 高 | 中（月200-1000元） |
| 企业/教育机构 | 15% | 私有部署、技术支持 | 高 | 高（月1000-5000元） |
| AI爱好者/开发者 | 10% | 本地折腾、技术探索 | 低 | 低 |

### 2.3 竞品分析

| 竞品 | 模式 | 优势 | 劣势 | 我们的差异化 |

## 三、商业模式

### 3.1 收入模型总览

```
收入来源
├── 1. 时间卡密体系（核心）
│   ├── 本地软件高级功能解锁
│   ├── 云电脑使用时长
│   └── 云端API调用额度

```

### 3.2 时间卡密体系（核心变现机制）

复用已有微信登录+卡密系统，统一为"云集时长卡"：

| 卡密类型 | 价格 | 内容 | 目标用户 |
|----------|------|------|---------|
| 体验卡 | 9.9元 | 2小时云端时长 + 7天高级功能 | 新用户转化 |
| 月卡 | 49元 | 10小时云端时长 + 30天高级功能 | 个人创作者 |
| 季卡 | 129元 | 40小时云端时长 + 90天高级功能 | 活跃用户 |
| 年卡 | 399元 | 200小时云端时长 + 365天高级功能 | 工作室 |
| 企业卡 | 面议 | 不限时 + 专属支持 + 私有部署 | 企业客户 |

**高级功能**（卡密解锁）：

- 批量生成队列（免费版限制3个，付费无限）
- 高清放大（免费版限制720p，付费支持1080p/4K）
- TTS语音克隆（付费专属）
- 多LoRA叠加（免费版限制1个，付费支持3个）
- 优先云端排队

### 3.3 云电脑代理模式

**核心思路**：不自己买GPU，代理云电脑厂商的算力，赚时间差价。

**合作厂商优先级**：

| 优先级 | 厂商 | 优势 | 接入难度 |
|--------|------|------|---------|
| 1 | AutoDL | 国内最大、API成熟、价格透明 | 低 |
| 2 | 矩池云 | 学术用户多、镜像丰富 | 低 |
| 3 | 恒源云 | 稳定、有企业版 | 中 |
| 4 | 其他（趋动云、揽睿星舟等） | 备选 | — |

**定价与利润模型**：

| GPU档位 | 云电脑成本（批发） | 用户售价 | 毛利率 |
|---------|-------------------|---------|--------|
| T4/3060 (16GB) | 1.5元/小时 | 3元/小时 | 50% |
| 4090 (24GB) | 4元/小时 | 8元/小时 | 50% |
| A100 (80GB) | 12元/小时 | 22元/小时 | 45% |

**技术实现方案**：

```
用户点击"云端模式"
  │
  ├─ 1. 检查卡密余额和登录状态
  │
  ├─ 2. 选择GPU档位 → 调用云电脑API创建实例
  │     实例预装：云集环境 + 全部模型 + 依赖
  │
  ├─ 3. 获取实例连接信息 → 启动器内嵌浏览器打开
  │     用户体验与本地模式一致
  │
  ├─ 4. 计时开始 → 每分钟扣减卡密时长
  │
  └─ 5. 用户点击"结束"或关闭窗口 → 释放实例 → 停止计费
```

**关键：预装镜像制作**

- 基于云电脑厂商的自定义镜像功能
- 预装：Python 3.12 + PyTorch + CUDA + 全部模型 + 云集后端
- 镜像大小约50-80GB（含模型），首次制作后可复用到所有实例
- 你已有完整的部署脚本（`_deploy_all`），可直接复用

### 3.4 1对1安装服务

| 服务等级 | 价格 | 内容 | 交付方式 |
|----------|------|------|---------|
| 基础安装 | 99元 | 远程安装+环境调试+首次生成演示 | 向日葵/ToDesk远程 |
| 标准服务 | 199元 | 以上+模型定制下载+LoRA配置+7天答疑 | 远程+微信答疑 |
| 高级服务 | 399元 | 以上+多模型配置+工作流优化+30天答疑 | 远程+微信答疑 |
| 企业部署 | 面议 | 多卡部署+批量生产流水线+私有化 | 现场或远程 |

**服务流程**：

1. 用户在软件内/官网/微信下单
2. 客服确认需求，预约时间
3. 远程连接，执行部署
4. 演示首次生成，确认完成
5. 建立微信答疑群

**成本**：你的时间成本，初期自己接单，后期可培训兼职客服。

### 3.5 云端API代理（中期）

在现有 LTX API / fal.ai 集成基础上增加计费层：

```
用户请求生成 → 云集后端 → 计费检查(卡密余额) → 转发至LTX API/fal.ai → 返回结果 → 扣减额度
```

- 无需自建GPU，纯API转发
- 加价比例：上游价格的1.5-2倍
- 优势：零运维成本，按量赚差价
