# 云集智能视频创意站 — 用户说明文档

---

## 一、软件简介

**云集智能视频创意站** 是一款基于 LTX-2.3 视频生成引擎的 AI 创意工具，由武汉市云集智能科技有限公司开发。软件集成了文生视频、图生视频、智能多帧拼接、视频迁移、图像生成、TTS 语音合成等核心功能，为创作者提供一站式 AI 视频创作体验。

- **核心引擎**：LTX-2.3 22B Distilled（支持 FP8 量化与 BF16 精度，8GB 显存即可启动）
- **技术架构**：PyQt6 桌面客户端 + FastAPI 后端 + Web 前端界面
- **运行环境**：Windows 10/11，NVIDIA GPU（最低 8GB 显存，推荐 24GB）

## 二、首次启动与部署

### 2.1 系统要求

#### 基础环境

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10 64位 | Windows 11 |
| GPU | NVIDIA 8GB 显存 | NVIDIA 24GB 显存 |
| 系统内存 | 32 GB | 64 GB |
| 磁盘 | 50 GB 可用空间 | 100 GB SSD |
| GPU 驱动 | ≥ 560.70 | 最新版本 |
| CUDA | 12.8（随 PyTorch 安装） | 12.8 |
| Python | 3.12 | 3.12 |
| 网络 | 需要联网下载模型 | 宽带 |

> **注意**：系统内存 32GB 是使用 CPU offload（低显存模式）的必要条件，因为模型权重需要暂存到内存中。低于 32GB 可能导致内存不足崩溃。

#### GPU 硬件分级

软件根据 GPU 显存大小自动匹配最优推理参数，分为 5 个等级：

| 等级 | 显存范围 | 代表显卡 | 推荐分辨率 | 速度参考 |
|------|---------|---------|-----------|---------|
| **极致性能** | 32GB+ | RTX 5090 / A6000 / A100 | 1080p | ≈10-20秒/25帧 |
| **高性能** | 20-31GB | RTX 3090 / 4090 / A5000 | 720p-1080p | ≈30-60秒/25帧 |
| **均衡模式** | 14-20GB | RTX 4080 / 3080 20GB / 5000 Ada | 720p | ≈30-60秒/25帧 |
| **节能模式** | 10-14GB | RTX 4070 Ti / 3080 12GB / 2080 Ti | 540p | ≈40-80秒/25帧 |
| **极限模式** | <10GB | RTX 4060 / 3060 / GTX 1080 Ti | 480p | ≈60-120秒/25帧 |

#### GPU 架构与加速特性

| GPU 架构 | 代表型号 | BF16 加速 | 原生 FP8 加速 | SageAttention |
|---------|---------|----------|-------------|--------------|
| **Blackwell** (SM_100) | RTX 5090 / 5080 / 5070 / 5060 | ✅ 硬件加速 | ✅ 硬件加速 | ✅ 支持 |
| **Ada Lovelace** (SM_89) | RTX 4090 / 4080 / 4070 / 4060 | ✅ 硬件加速 | ✅ 硬件加速 | ✅ 支持 |
| **Ampere** (SM_86) | RTX 3090 / 3080 / 3080 Ti / A5000 | ✅ 硬件加速 | ❌ 软件模拟 | ❌ 不支持 |
| **Turing** (SM_75) | RTX 2080 Ti / 2080 / 2070 | ❌ 软件模拟 | ❌ 软件模拟 | ❌ 不支持 |
| **Pascal** (SM_61) | GTX 1080 Ti / 1080 / 1070 | ❌ 不支持 | ❌ 不支持 | ❌ 不支持 |

> **说明**：BF16 和 FP8 的"软件模拟"指 PyTorch 会自动将低精度运算转换为 FP32/FP16 执行，功能正常但无硬件加速收益。Pascal 架构不支持 BF16，会回退到 FP32 计算。

#### 模型选择建议

软件提供两种精度的模型，根据显卡显存选择：

| 模型 | 文件大小 | 精度 | 适用显卡 | 说明 |
|------|---------|------|---------|------|
| **BF16 蒸馏模型** | ~44GB | 原始精度，无损 | 24GB+ 显存 | 画质最佳，需配合 Layer Streaming 分段加载 |
| **FP8 蒸馏模型** | ~22GB | 权重量化，轻微损失 | 8GB+ 显存 | 画质略低，显存占用减半，推荐大多数用户使用 |

> **Layer Streaming（分段加载）**：当模型权重无法全部放入显存时，软件自动启用分段加载策略——将 Transformer 层保存在 CPU 内存中，按需异步传输到 GPU 计算，计算完毕立即释放。这使得 44GB 的 BF16 模型也能在 24GB 显卡上运行，代价是推理速度会因 CPU↔GPU 数据搬运而降低。

#### 各等级详细帧预算

帧预算指当前显存等级下能生成的**最大总帧数**（num_frames），受分辨率和帧率共同影响。调高帧率 → 推荐秒数自动缩短。

| 等级 | 分辨率 | 最大帧数 | 推荐帧数 | 推荐帧率 |
|------|--------|---------|---------|---------|
| 极致 | 1080p | 401 | 257 | 24/25/30 |
| 极致 | 720p | 569 | 401 | 24/25/30 |
| 高性能 | 1080p | 257 | 161 | 24/25 |
| 高性能 | 720p | 401 | 257 | 24/25/30 |
| 均衡 | 1080p | 89 | 57 | 24 |
| 均衡 | 720p | 161 | 97 | 24/25 |
| 节能 | 720p | 89 | 57 | 24 |
| 节能 | 540p | 161 | 97 | 24/25 |
| 极限 | 540p | 89 | 57 | 24 |
| 极限 | 480p | 161 | 97 | 24 |

### 2.2 自动部署

首次启动时，软件将自动完成以下部署步骤：

1. **下载 UV 包管理器**（国内镜像加速）
2. **安装 Python 3.12** 并创建虚拟环境（`data/.venv/`）

5. **下载 LTX Desktop 后端代码**
6. **下载 AI 模型**（HF-Mirror 国内镜像加速）

> 整个部署过程约需 15-30 分钟（取决于网速），请耐心等待。

#### 基础画面设置

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 清晰度级别 | 输出分辨率档位 | 1080P / 720P / 540P |

| 输入 | 效果 |

### 4.2 智能多帧

将多张图片智能编排为连续视频，支持两种工作流：

| 模式 | 说明 |
|------|------|
| **单次多关键帧** | 所有图片作为一条视频的关键帧锚点，一次生成完整视频 |
| **分段拼接** | 每两张图片生成一段视频，再通过 ffmpeg 拼接为完整成片 |

#### 操作步骤

1. 点击上传区域或拖入多张图片
2. 在缩略图条中**拖拽排序**（顺序 = 播放先后）
3. 选择工作流模式和画面参数
4. 可选：上传 BGM 配乐（生成后自动替换整段音轨）
5. 点击「开始渲染」

> 分段拼接模式需要系统安装 ffmpeg。可通过以下方式配置：
> - 将 ffmpeg 加入系统 PATH
> - 设置环境变量 `LTX_FFMPEG_PATH`
> - 在 `%LOCALAPPDATA%\LTXDesktop\ffmpeg_path.txt` 第一行写入 ffmpeg.exe 完整路径

### 4.5 高清放大

对已有的视频或图片进行分辨率放大，提升画面清晰度。支持两种引擎和多种目标分辨率模式。

#### 放大引擎

| 引擎 | 技术原理 | 速度 | 质量 | 适用场景 |
|------|---------|------|------|---------|
| **Real-ESRGAN（高保真）** | 逐帧 AI 超分辨率，模型推理增强细节 | 慢（分钟级） | 高（AI 细节增强） | 对画质要求高的正式输出 |
| **LTX 快速放大** | ffmpeg Lanczos 插值，单次命令完成 | 极快（秒级） | 中（传统插值，无细节增强） | 快速预览或对质量要求不高的场景 |

> **提示**：选择「LTX 快速放大」时，模型选择、降噪强度和分块大小设置将自动隐藏（这些参数仅对 Real-ESRGAN 引擎有效）。

#### 放大类型

| 类型 | 说明 |
|------|------|
| **视频放大** | 对视频逐帧放大，输出高分辨率视频 |
| **图片放大** | 对单张图片放大，输出高分辨率图片 |

> **注意**：LTX 快速放大引擎仅支持视频放大。图片放大请使用 Real-ESRGAN 引擎。

#### 画面比例与分辨率

高清放大采用**两步式**分辨率选择：先选择画面比例，再选择目标清晰度。

**第一步：选择画面比例**

| 选项 | 说明 |
|------|------|
| 原始比例 | 保持源视频/图片的宽高比不变 |
| 16:9 横屏 | 输出为 16:9 横屏比例 |
| 9:16 竖屏 | 输出为 9:16 竖屏比例 |
| 1:1 方形 | 输出为 1:1 正方形比例 |
| 4:3 传统 | 输出为 4:3 传统比例 |
| 按倍数放大 | 不指定目标分辨率，按固定倍数放大 |
| 自定义尺寸 | 手动输入目标宽度和高度 |

**第二步：选择目标清晰度**（原始比例和预设比例时显示）

| 清晰度 | 短边像素 | 说明 |
|--------|---------|------|
| 720P 高清 | 720 | 标准高清 |
| 1080P 全高清 | 1080 | 全高清（默认） |
| 2K 超清 | 1440 | 2K 超清 |
| 4K 极清 | 2160 | 4K 极清 |

> **原始比例模式**：选择「原始比例」时，软件自动以目标清晰度的短边像素为基准，按源视频/图片的实际宽高比计算输出分辨率。例如，源视频为 480×832（竖屏），选择 1080P 时，输出为 1080×1872。

> **预设比例模式**：选择 16:9、9:16 等预设比例时，软件按目标清晰度和选定比例计算输出分辨率。例如，选择 16:9 + 1080P 时，输出为 1920×1080。

#### 放大倍数（按倍数模式）

| 倍数 | 说明 |
|------|------|
| 2 倍 (2x) | 输出尺寸为原始的 2 倍 |
| 4 倍 (4x) | 输出尺寸为原始的 4 倍 |

> 实际放大倍数由 AI 模型决定（如 x4plus 模型固定 4 倍放大），软件会在内部自动处理倍数与模型的匹配。

#### 自定义尺寸与缩放模式

选择「自定义尺寸」时，可手动输入目标宽度和高度，并选择缩放模式：

| 缩放模式 | 说明 |
|---------|------|
| 适应（Fit） | 保持原始比例缩放，可能留黑边 |
| 裁剪（Crop） | 保持原始比例缩放，裁剪超出部分 |
| 拉伸（Stretch） | 拉伸到指定尺寸，可能变形 |

#### Real-ESRGAN 专属参数

以下参数仅在 Real-ESRGAN 引擎下显示：

| 参数 | 说明 |
|------|------|
| **放大模型** | 通用 x4plus（默认，适合真实照片）、动漫 x4plus-anime（适合动画/插画）、通用 x2plus（2 倍放大） |
| **降噪强度** | 0-1，默认 0.5。0 = 保留原始细节，1 = 强力降噪。值越高降噪越强但可能丢失细节 |
| **分块大小 (Tile)** | 0 = 自动根据显存设置。值越小越省显存但越慢。自动模式下会根据 GPU 显存自动选择最优值 |

#### 操作步骤

1. 点击左侧面板「高清放大」标签页
2. 选择放大类型：视频放大或图片放大
3. 上传待放大的视频或图片文件
4. 选择放大引擎（Real-ESRGAN 或 LTX 快速放大）
5. 选择画面比例和目标清晰度
6. 根据需要调整引擎专属参数
7. 点击顶部「🔍 开始高清放大」按钮

> 高清放大任务会进入任务队列，与视频渲染、TTS 语音任务统一排队执行。可在任务队列中查看进度。

#### 历史资产中的放大参数

高清放大完成后，在历史资产记录中会显示以下参数：

| 参数 | 说明 |
|------|------|
| 模式 | 原始比例 / 目标分辨率 / 按倍数 |
| 放大 | 实际放大倍数（如 2x、4x） |
| 模型 | 使用的 AI 模型名称 |
| 原始 | 源视频/图片的分辨率 |
| 输出 | 输出视频/图片的分辨率 |
| 帧数 | 视频的总帧数 |
| 耗时 | 放大处理耗时 |

## 六、模型管理

点击底部「模型管理」按钮打开模型管理弹窗。

模型按目录分组展示，默认展开系统模型目录：

- **📂 自定义目录** — 用户添加的额外模型目录，文件可删除

### 6.2 添加模型目录

1. 在底部输入框中输入模型目录的完整路径
2. 点击「添加」按钮
3. 新目录将出现在目录树中

### 6.3 删除模型文件

- 系统默认目录中的模型**不允许删除**（保护核心文件）

- 点击删除前会弹出确认提示

### 6.4 支持的模型格式

`.safetensors`、`.ckpt`、`.pt`、`.bin`、`.pth`

### 6.5 LoRA 文件放置

## 十一、常见问题

### Q1：首次启动部署失败？

- 检查网络连接，确保能访问国内镜像源
- 关闭杀毒软件/防火墙后重试
- 查看 `temp/logs/` 目录下的日志文件

### Q2：生成时显存不足？

- 在系统设置中设置显存上限（建议设为实际显存的 90%）
- 使用 FP8 量化模型（仅需约 22GB 显存，8GB 显卡即可运行）
- 降低清晰度级别（540P 代替 1080P）
- 缩短视频时长（减少总帧数）
- 点击「释放显存」清理缓存
- 确保系统内存 ≥ 32GB（低显存模式需要将权重暂存到内存）

### Q3：BF16 模型和 FP8 模型怎么选？

- **24GB+ 显存**：推荐 BF16 模型，画质最佳，软件自动启用 Layer Streaming 分段加载
- **8-24GB 显存**：推荐 FP8 模型，显存占用减半，稳定性更好
- **BF16 模型的优势**：权重无量化损失，生成质量略高
- **FP8 模型的优势**：体积小一半，推理时显存压力更小，速度更快
- 两种模型的**计算精度相同**（均为 BF16），区别仅在于权重存储精度

### Q4：视频无法播放？

- 确保后端服务正在运行（核心引擎状态为绿色）
- 刷新浏览器页面
- 检查 `temp/logs/` 目录下的错误日志

### Q5：模型列表为空？

- 点击模型仓库旁的「刷新」按钮
- 确认模型文件已正确放置在 `data/models/` 目录下
- 支持的格式：`.safetensors`、`.ckpt`、`.pt`、`.bin`、`.pth`

### Q6：分段拼接失败？

- 确认系统已安装 ffmpeg
- 可通过环境变量 `LTX_FFMPEG_PATH` 指定 ffmpeg 路径
- 或在 `%LOCALAPPDATA%\LTXDesktop\ffmpeg_path.txt` 中写入路径

### Q7：软件自动退出？

- 查看 `temp/logs/crash.log` 和 `temp/logs/qt_exception.log`
- 如果是 0xC0000005 错误，软件会自动重试（最多 2 次）
- 确保显卡驱动为最新版本
- 尝试降低显存使用量

### Q8：TTS 语音合成不可用？

- TTS 功能需要额外下载 TTS 模型
- 首次使用时软件会自动检测并提示下载
- 确保后端服务正常运行

### Q9：推理速度很慢怎么办？

- **使用 FP8 模型**：显存占用减半，Layer Streaming 搬运量减半，速度显著提升
- **降低分辨率**：540P 比 1080P 快 3-5 倍
- **减少帧数**：帧数是影响推理时间的最直接因素
- **确保系统内存充足**：64GB 内存时 offload 性能开销较小
- **升级显卡**：RTX 40 系列（Ada Lovelace）支持原生 FP8 硬件加速，推理速度更快
- **关闭 upscaler**：在低显存模式下，软件会自动关闭超分辨率模块以释放显存

### Q10：高清放大速度很慢？

- **使用 LTX 快速放大引擎**：基于 ffmpeg Lanczos 插值，秒级完成，适合快速预览
- **增大分块大小**：分块越大处理越快，但需要更多显存。设为 0 可自动根据显存选择最优值
- **使用动漫模型**：`x4plus-anime` 模型通常比通用 `x4plus` 模型更快
- **降低目标清晰度**：720P 比 4K 处理速度快得多

### Q11：高清放大后画面质量不佳？

- **高保真放大**：使用 Real-ESRGAN 引擎，AI 模型会增强细节，画质最佳
- **快速放大**：LTX 快速放大使用传统插值算法，不会增加画面细节，仅做分辨率缩放
- **降噪强度**：Real-ESRGAN 引擎下，降噪值过高可能丢失细节，过低可能保留噪点。建议默认 0.5
- **模型选择**：真实照片推荐 `x4plus`，动画/插画推荐 `x4plus-anime`

### Q12：高清放大任务失败？

- 确保后端服务正在运行（核心引擎状态为绿色）
- 确认已安装 Real-ESRGAN 依赖（首次使用时软件会自动检测并提示安装）
- 检查 `temp/logs/` 目录下的错误日志
- 如果是显存不足，尝试减小分块大小或降低目标分辨率
