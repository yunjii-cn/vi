使用说明

云集智能视频创意站 — AI 视频创作一站式工具

一、软件简介

云集智能视频创意站是一款基于 LTX-2.3 视频生成引擎的 AI 创意工具，由武汉市云集智能科技有限公司开发。集成了文生视频、图生视频、智能多帧拼接、视频迁移、图像生成、TTS 语音合成等核心功能。

  • 核心引擎：LTX-2.3 22B Distilled（支持 FP8 量化与 BF16 精度，8GB 显存即可启动）
  • 技术架构：PyQt6 桌面客户端 + FastAPI 后端 + Web 前端界面
  • 运行环境：Windows 10/11，NVIDIA GPU（最低 8GB 显存，推荐 24GB）

BF16 和 FP8 的"软件模拟"指 PyTorch 会自动将低精度运算转换为 FP32/FP16 执行，功能正常但无硬件加速收益。Pascal 架构不支持 BF16，会回退到 FP32 计算。

模型选择建议

BF16 蒸馏模型 ~44GB
原始精度，无损画质。适用于 24GB+ 显存，需配合 Layer Streaming 分段加载。
FP8 蒸馏模型 ~22GB
权重量化，轻微损失。显存占用减半，8GB+ 显存即可运行，推荐大多数用户。
Layer Streaming（分段加载）：当模型权重无法全部放入显存时，软件自动启用分段加载策略——将 Transformer 层保存在 CPU 内存中，按需异步传输到 GPU 计算，计算完毕立即释放。这使得 44GB 的 BF16 模型也能在 24GB 显卡上运行，代价是推理速度会因 CPU↔GPU 数据搬运而降低。

三、首次启动与部署

首次启动时，软件将自动完成以下部署步骤：

  1. 下载 UV 包管理器（国内镜像加速）
  2. 安装 Python 3.12 并创建虚拟环境（data/.venv/）
  3. 安装 PyTorch + CUDA 12.8 及项目依赖
  4. 部署补丁文件和前端界面
  5. 下载 LTX Desktop 后端代码
  6. 下载 AI 模型（HF-Mirror 国内镜像加速）
整个部署过程约需 15-30 分钟（取决于网速），请耐心等待。

AI 环境音

勾选「生成 AI 环境音」后，视频生成完毕将自动添加匹配场景的 AI 音效。

5.2 智能多帧

将多张图片智能编排为连续视频，支持两种工作流：

单次多关键帧
所有图片作为一条视频的关键帧锚点，一次生成完整视频。
分段拼接
每两张图片生成一段视频，再通过 ffmpeg 拼接为完整成片。

操作步骤：上传图片 → 拖拽排序 → 选择模式 → 可选上传 BGM → 开始渲染

分段拼接模式需要系统安装 ffmpeg。可通过环境变量 LTX_FFMPEG_PATH 指定路径。

5.3 视频迁移

将参考视频中的动作/运镜/风格迁移到新主体上。

迁移类型说明
动作迁移提取参考视频中的姿态/轮廓/深度，驱动目标图片
运镜迁移复制参考视频的镜头运动轨迹
视频重绘保持原视频结构，重新生成画面风格

控制类型（动作迁移）

类型说明
Pose 姿态提取人体骨骼姿态
Canny 轮廓提取边缘轮廓
Depth 深度提取深度图

控制强度：范围 0-2，默认 1。值越大参考视频控制力越强，值越小 AI 创作自由度越高。

注意力强度：范围 0-1，默认 1。控制模型对参考视频信号的关注程度，值越大迁移效果越强。

当前 IC-LoRA 架构使用 SimpleDenoiser（无 CFG 引导），且 Union-Control 模型为 canny+depth+pose 联合控制，非专用姿态模型，因此姿态迁移精度有限。提高注意力强度可增强参考信号的影响力，但无法达到 ControlNet 级别的精确控制。

5.4 图像生成

基于 LTX-2.3 引擎生成静态图像。

参数说明
预设分辨率1:1 (1024×1024)、16:9 (1280×720)、9:16 (720×1280)、自定义
采样步数1-50，默认 28。步数越多细节越丰富，但耗时更长

5.5 TTS 语音

TTS 语音功能包含四个子模式：文字转语音、语音转文字、声音克隆、终极克隆，通过子标签页切换，参数共享。

文字转语音
输入文本，AI 自动设计声音风格。
语音转文字
上传音频文件，自动识别为文字，支持中英文。识别结果可一键复制。
声音克隆
上传参考音频，模仿其音色合成新文本。点击「识别为文字」可自动将参考音频转为文本。
终极克隆
上传参考音频 + 对应文本转录，最高还原度。点击「识别为文字」可自动填充文本转录。

在文本开头加英文括号描述声音特征，例如：(年轻女声，温柔甜美) 你好，欢迎来到...

5.6 超分放大

超分放大功能支持对图片和视频进行高分辨率增强，通过子标签页切换视频放大和图片放大。

参数说明可选值
超分引擎选择超分算法Real-ESRGAN（高保真）/ LTX 快速超分
放大倍数输出分辨率相对输入的倍数2x / 4x
超分模型Real-ESRGAN 模型变体通用 x4plus / 动漫 x4plus-anime / 通用 x2plus
降噪强度控制降噪程度0-1，0=保留原始细节，1=强力降噪
Real-ESRGAN（高保真）
基于深度学习的超分辨率算法，支持通用和动漫模型，适合对画质要求高的场景。需要安装 realesrgan 和 basicsr 依赖。
LTX 快速超分
基于 LTX 内置空间上采样器的快速超分，速度极快但非保真增强，适合快速预览。

九、常见问题

Q: 首次启动部署失败？
  • 检查网络连接，确保能访问国内镜像源
  • 关闭杀毒软件/防火墙后重试
  • 查看 temp/logs/ 目录下的日志文件
Q: 生成时显存不足？
  • 在系统设置中设置显存上限（建议设为实际显存的 90%）
  • 使用 FP8 量化模型（仅需约 22GB 显存，8GB 显卡即可运行）
  • 降低清晰度级别（540P 代替 1080P）
  • 缩短视频时长（减少总帧数）
  • 点击「释放显存」清理缓存
  • 确保系统内存 ≥ 32GB
Q: BF16 模型和 FP8 模型怎么选？
  • 24GB+ 显存：推荐 BF16 模型，画质最佳，软件自动启用 Layer Streaming
  • 8-24GB 显存：推荐 FP8 模型，显存占用减半，稳定性更好
  • 两种模型的计算精度相同（均为 BF16），区别仅在于权重存储精度
Q: 推理速度很慢怎么办？
  • 使用 FP8 模型：显存占用减半，Layer Streaming 搬运量减半，速度显著提升
  • 降低分辨率：540P 比 1080P 快 3-5 倍
  • 减少帧数：帧数是影响推理时间的最直接因素
  • 确保系统内存充足：64GB 内存时 offload 性能开销较小
  • 升级显卡：RTX 40/50 系列支持原生 FP8 硬件加速
Q: 视频无法播放？
  • 确保后端服务正在运行（核心引擎状态为绿色）
  • 刷新浏览器页面
  • 检查 temp/logs/ 目录下的错误日志
Q: 模型列表为空？
  • 点击模型仓库旁的「刷新」按钮
  • 确认模型文件已正确放置在 data/models/ 目录下
Q: 分段拼接失败？
  • 确认系统已安装 ffmpeg
  • 可通过环境变量 LTX_FFMPEG_PATH 指定 ffmpeg 路径
Q: 软件自动退出？
  • 查看 temp/logs/crash.log 和 temp/logs/qt_exception.log
  • 如果是 0xC0000005 错误，软件会自动重试（最多 2 次）
  • 确保显卡驱动为最新版本
  • 尝试降低显存使用量
