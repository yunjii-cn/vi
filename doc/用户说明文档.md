# 云集智能视频创意站 — 用户说明文档

---

## 一、软件简介

**云集智能视频创意站** 是一款基于 LTX-2.3 视频生成引擎的 AI 创意工具，由武汉市云集智能科技有限公司开发。软件集成了文生视频、图生视频、智能多帧拼接、视频迁移、图像生成、TTS 语音合成等核心功能，为创作者提供一站式 AI 视频创作体验。

- **核心引擎**：LTX-2.3 22B Distilled（支持 FP8 量化，10GB 显存即可运行）
- **技术架构**：PyQt6 桌面客户端 + FastAPI 后端 + Web 前端界面
- **运行环境**：Windows 10/11，NVIDIA GPU（推荐 10GB 以上显存）

## 二、首次启动与部署

### 2.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10 64位 | Windows 11 |
| GPU | NVIDIA 8GB 显存 | NVIDIA 24GB 显存 |
| 内存 | 16 GB | 32 GB |
| 磁盘 | 50 GB 可用空间 | 100 GB SSD |
| 网络 | 需要联网下载模型 | 宽带 |

### 2.2 自动部署

首次启动时，软件将自动完成以下部署步骤：

1. **下载 UV 包管理器**（国内镜像加速）
2. **安装 Python 3.12** 并创建虚拟环境（`data/.venv/`）
3. **安装 PyTorch + CUDA 12.8** 及项目依赖
4. **部署补丁文件和前端界面**
5. **下载 LTX Desktop 后端代码**
6. **下载 AI 模型**（HF-Mirror 国内镜像加速）

> 整个部署过程约需 15-30 分钟（取决于网速），请耐心等待。

### 2.3 目录结构

```
app/                ← 应用程序（只读，纯净可发布）
app/resources/      ← 后端、补丁、前端等资源
data/               ← 用户数据（可写，需要备份）
data/.venv/         ← Python 虚拟环境
data/outputs/       ← 生成的视频/图像/音频
data/uploads/       ← 上传的参考图片
data/models/        ← AI 模型文件
data/settings.json  ← 用户设置
temp/               ← 临时文件（可删除，无需备份）
temp/logs/          ← 日志文件
```

## 四、功能模块详解

### 4.1 视频生成

核心功能，支持文生视频和图生视频。

#### 基础画面设置

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 清晰度级别 | 输出分辨率档位 | 1080P / 720P / 540P |
| 画幅比例 | 视频宽高比 | 16:9、9:16、1:1、4:3、3:4、21:9、9:21、跟随参考图、自定义 |
| 帧率 (FPS) | 每秒帧数 | 24 / 25 / 30 / 48 / 60 |
| 时长 | 视频秒数 | 1-30 秒 |
| 镜头运动 | 摄像机运动方式 | 静止、推近、拉远、向左、向右、升臂、降臂、焦点偏移 |

#### 生成媒介

| 输入 | 效果 |
|------|------|
| 仅文字描述 | 文生视频（Text-to-Video） |
| 上传首帧图片 | 图生视频（Image-to-Video） |
| 上传首帧 + 尾帧 | 首尾插帧（Frame Interpolation） |
| 上传首帧 + 参考音频 | 音频驱动视频（Audio-to-Video） |

#### LoRA 增强

- 点击 **+** 按钮添加多个 LoRA
- 每个 LoRA 可独立设置权重（0-2）
- LoRA 文件需放置在模型目录下的 `loras` 文件夹中

#### AI 环境音

勾选「生成 AI 环境音」后，视频生成完毕将自动添加匹配场景的 AI 音效。

---

### 4.2 智能多帧

将多张图片智能编排为连续视频，支持两种工作流：

| 模式 | 说明 |
|------|------|
| **单次多关键帧** | 所有图片作为一条视频的关键帧锚点，一次生成完整视频 |
| **分段拼接** | 每两张图片生成一段视频，再通过 ffmpeg 拼接为完整成片 |

#### 操作步骤

1. 点击上传区域或拖入多张图片
2. 在缩略图条中**拖拽排序**（顺序 = 播放先后）
3. 选择工作流模式和画面参数
4. 可选：上传 BGM 配乐（生成后自动替换整段音轨）
5. 点击「开始渲染」

> 分段拼接模式需要系统安装 ffmpeg。可通过以下方式配置：
> - 将 ffmpeg 加入系统 PATH
> - 设置环境变量 `LTX_FFMPEG_PATH`
> - 在 `%LOCALAPPDATA%\LTXDesktop\ffmpeg_path.txt` 第一行写入 ffmpeg.exe 完整路径

---

### 4.3 视频迁移

将参考视频中的动作/运镜/风格迁移到新主体上。

| 迁移类型 | 说明 |
|---------|------|
| **动作迁移** | 提取参考视频中的姿态/轮廓/深度，驱动目标图片 |
| **运镜迁移** | 复制参考视频的镜头运动轨迹 |
| **视频重绘** | 保持原视频结构，重新生成画面风格 |

#### 控制类型（动作迁移）

| 类型 | 说明 |
|------|------|
| Pose 姿态 | 提取人体骨骼姿态 |
| Canny 轮廓 | 提取边缘轮廓 |
| Depth 深度 | 提取深度图 |

#### 控制强度

- 范围 0-2，默认 1
- 值越大，参考视频的控制力越强；值越小，AI 创作自由度越高

---

### 4.4 图像生成

基于 LTX-2.3 引擎生成静态图像。

| 参数 | 说明 |
|------|------|
| 预设分辨率 | 1:1 (1024×1024)、16:9 (1280×720)、9:16 (720×1280)、自定义 |
| 采样步数 | 1-50，默认 28。步数越多细节越丰富，但耗时更长 |

---

### 4.5 TTS 语音合成

将文本转换为自然语音，支持声音克隆。

| 模式 | 说明 |
|------|------|
| **文字转语音** | 输入文本，AI 自动设计声音风格 |
| **声音克隆** | 上传参考音频，模仿其音色合成新文本 |
| **终极克隆** | 上传参考音频 + 对应文本转录，最高还原度 |

#### 声音描述

在文本开头加英文括号描述声音特征，例如：
- `(年轻女声，温柔甜美)` 你好，欢迎来到...
- `(中年男声，沉稳有力)` 今天的新闻...

#### 高级参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| CFG 强度 | 0.5-5.0 | 2.0 | 值越大越贴合文本描述 |
| 推理步数 | 5-50 | 10 | 步数越多质量越高 |

## 六、模型管理

点击底部「模型管理」按钮打开模型管理弹窗。

### 6.1 目录树结构

模型按目录分组展示，默认展开系统模型目录：

- **📁 系统模型目录** — 软件默认的模型存放路径，文件不可删除
- **📂 自定义目录** — 用户添加的额外模型目录，文件可删除

点击目录行左侧的 ▶ 按钮展开/折叠，查看目录下的所有模型文件。

### 6.2 添加模型目录

1. 在底部输入框中输入模型目录的完整路径
2. 点击「添加」按钮
3. 新目录将出现在目录树中

### 6.3 删除模型文件

- 系统默认目录中的模型**不允许删除**（保护核心文件）
- 自定义目录中的模型，每行右侧显示「删除」按钮
- 点击删除前会弹出确认提示

### 6.4 支持的模型格式

`.safetensors`、`.ckpt`、`.pt`、`.bin`、`.pth`

### 6.5 LoRA 文件放置

将 LoRA 文件放到当前模型目录下的 `loras` 子文件夹中，或在系统设置中指定自定义 LoRA 目录路径。

## 十一、常见问题

### Q1：首次启动部署失败？

- 检查网络连接，确保能访问国内镜像源
- 关闭杀毒软件/防火墙后重试
- 查看 `temp/logs/` 目录下的日志文件

### Q2：生成时显存不足？

- 在系统设置中降低显存上限
- 使用 FP8 量化模型（仅需 10GB 显存）
- 降低清晰度级别（540P 代替 1080P）
- 缩短视频时长
- 点击「释放显存」清理缓存

### Q3：视频无法播放？

- 确保后端服务正在运行（核心引擎状态为绿色）
- 刷新浏览器页面
- 检查 `temp/logs/` 目录下的错误日志

### Q4：模型列表为空？

- 点击模型仓库旁的「刷新」按钮
- 确认模型文件已正确放置在 `data/models/` 目录下
- 支持的格式：`.safetensors`、`.ckpt`、`.pt`、`.bin`、`.pth`

### Q5：分段拼接失败？

- 确认系统已安装 ffmpeg
- 可通过环境变量 `LTX_FFMPEG_PATH` 指定 ffmpeg 路径
- 或在 `%LOCALAPPDATA%\LTXDesktop\ffmpeg_path.txt` 中写入路径

### Q6：软件自动退出？

- 查看 `temp/logs/crash.log` 和 `temp/logs/qt_exception.log`
- 如果是 0xC0000005 错误，软件会自动重试（最多 2 次）
- 确保显卡驱动为最新版本
- 尝试降低显存使用量

### Q7：TTS 语音合成不可用？

- TTS 功能需要额外下载 TTS 模型
- 首次使用时软件会自动检测并提示下载
- 确保后端服务正常运行
